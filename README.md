# RimMind .github

本仓库用于存放 [RimMind Organization](https://github.com/RimWorld-RimMind-Mod) 的社区健康文件和 GitHub 配置。

## 包含的文件

| 文件 | 说明 |
|------|------|
| `profile/README.md` | 组织主页展示内容 |
| `CONTRIBUTING.md` | 贡献指南 |
| `CODE_OF_CONDUCT.md` | 行为准则 |
| `LICENSE` | 许可证 |
| `ISSUE_TEMPLATE/` | Issue 模板 |
| `PULL_REQUEST_TEMPLATE.md` | PR 模板 |

## 作用范围

这些文件会自动应用于组织下的所有仓库。如果某个仓库需要自定义配置，可以在其自身目录下创建同名文件覆盖。
